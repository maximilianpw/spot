# Collecte d'information

Phase **Découverte** du [cycle de vie d'un projet web](../../../cours/cahier-des-charges/02-cycle-de-vie-projet-web.pdf) : enquête client et collecte de supports.

**Objectif :** réunir auprès du client toutes les informations et tous les supports nécessaires pour rédiger le cahier des charges.

**Échéance :** semaines 1 et 2, du 30/09 au 10/10 (livrable « Enquêtes clients » du [planning](../../../cours/cahier-des-charges/03-planning.pdf)).

## Démarche

1. **Préparer** : relire le guide d'entretien, retirer les questions inutiles, fixer le rendez-vous avec le client.
2. **Mener l'entretien** (45 min à 1 h) avec le [guide d'entretien](guide-entretien-client.md). Une personne pose les questions, une autre prend des notes.
3. **Récupérer les supports** avec la [checklist](supports-a-collecter.md) : noter qui fournit quoi et pour quand.
4. **Synthétiser** : remplir la [synthèse](synthese.md) sous 48 h et la faire valider par le client.

## Et ensuite

La synthèse validée alimente les autres tâches de la Découverte (cibles, objectifs, analyse des concurrents, date de lancement) puis le cahier des charges.
